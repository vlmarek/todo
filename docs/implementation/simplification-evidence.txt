Implemented changes
-------------------
- Removed fixture-only lifecycle discovery/publication code. Shared builders,
  scripted transports and setup now live in tests/support; ordinary fixture
  objects own cleanup instead of invoking a second TestCase's lifecycle.
  Discovery no longer needs identity deduplication. Two lifecycle scenario names
  changed to describe retained saved evidence; original scenarios remain covered.
- Shared the production move-destination selector, retaining exact category names,
  bounded item matching and explicit parent/category destination behavior.
- Added operation-local validated hierarchy contexts for queue generation,
  selection, rendering, diagnostics, lifecycle previews, retained move context,
  report selection and history pruning. Public traversal helpers still validate
  complete input. No persistent or snapshot-identity cache was introduced.
- Shared comment and queue ordering, reminder offset units, escaped item paths,
  and consumed current/completed task scalar conversions. Endpoint relevance
  filtering and tombstone handling remain before task field interpretation.
- Centralized publication observations while retaining workflow-specific failure
  wording/recovery policy and initialization's additional cursor destination.
  Diagnostic failures cannot erase the original failure.
- Gateway Result/MutationInterrupted now carry attributable outcome, accumulated
  evidence and safe diagnostics. Workflow transport wrappers were removed.
  Explicit pre-dispatch refusals remain unattempted; interruption retains exact
  UUID/temp-ID proof, redaction and replay prevention.
- Shared saved-context merging with an explicit collection-authority policy.
  Ordinary reads do not repeat an already completed merge. Initialization keeps
  its different retention policy. Descendant ID closure supports incomplete and
  cyclic intermediate graphs; final hierarchy validation remains separate.
- Reused decoded publication values and serialized already-validated models.
  All caller-supplied candidate bytes are checked before the first replacement;
  immutable byte sets are frozen per operation. Public codec/model checks remain.
  Unchanged normalized item/comment records are reused.
